## 7. Floating image position and 1920px behavior

This is a key requirement. The main image must align to the **right edge of the viewport** from `992px` through `1920px`, then stop moving farther right when the viewport exceeds `1920px`.

### From 992px through 1920px

- Align the image's right edge with the viewport's right edge, even though the text remains aligned to the existing `.container`.
- Scale the image fluidly as the viewport grows. Keep its aspect ratio and use an appropriate maximum size.
- The image should visually extend beyond the text container into the right-side area; do not constrain its right edge to the `.container` edge.
- Maintain enough separation from the text and navigation to avoid overlap.
- The section background should extend across the available viewport width as shown in the reference.

### Above 1920px

- Freeze the image's horizontal position at the position it has when the viewport is exactly `1920px` wide.
- The image must not keep moving towards the right edge of wider viewports. Extra viewport width should remain to the right of the image.
- Do not center the image relative to the wider viewport or recalculate its layout around the current viewport center.
- Keep the image at or below its maximum size so it no longer grows beyond the design's reference scale.

A possible CSS strategy, if the containing block spans the viewport as required, is to use an image element positioned absolutely relative to the full-width section and a right offset such as `right: max(0px, calc(100vw - 1920px))`. Combine this with a responsive width and a maximum width chosen from the visual reference. Adapt it to the actual DOM and test it; do not paste it blindly if the element's containing block is the `.container` instead of the full-width section.

- Do not modify the Bootstrap `.container` to achieve this.
- Verify the actual containing block and existing position rules before choosing the CSS technique.
- Preserve the image's intrinsic ratio using `height: auto` or a verified aspect ratio; use `object-fit: contain` if needed. Do not use `cover` if it crops the reference image.
- Reserve vertical space for the absolutely positioned image so the Hero does not collapse.
- Do not use `position: fixed`; the image belongs to this section.
- At mobile/tablet widths, reset positioning so the image returns to normal flow between paragraph and selector.
- If the requirement cannot be achieved within the base skill's allowed file boundaries, report it explicitly. Never modify global files to work around the limitation.

## 9. Functional mobile selector

- Use the configured ACF Link URL as the option value and its configured link title as the label. Do not duplicate destinations in a separate hardcoded list.

- When the user changes the selection, navigate to the selected link's configured destination.
- For same-page hash destinations, preserve normal hash navigation and allow the browser to scroll to the corresponding target.
- For ordinary URLs, navigate to that URL.
- Carry the configured link target into the option data when necessary. If the link target is `_blank`, open it in a new browsing context in response to the user's selection action; use safe `noopener`/`noreferrer` behavior as appropriate. Do not silently convert every link to same-tab navigation.
